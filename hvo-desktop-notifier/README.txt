Hyvision One Notifier (Windows tray)
===========================

Lightweight tray notifier for Hyvision One.
- Shows Windows balloon tips for new Hyvision One notifications
- Runs in system tray (no browser required while running)
- Does NOT enable Startup by default
- Does NOT modify OS system settings

Install
-------
1. Unzip
2. Run Install.bat
3. Enter API Base URL (example: https://your-server/api) and login

Uninstall
---------
Run Uninstall.bat

Notes
-----
- Requires Windows PowerShell and network access to Hyvision One API
- Right-click tray icon: Open Hyvision One / Check now / Notifications ON·OFF / Re-login / Exit
